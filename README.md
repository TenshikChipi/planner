# ✳ по плану. — сайт домашних заданий учебной группы

Готовый сайт с месячным календарём и обзором четырёх недель, списком заданий, фильтрами, прикреплёнными файлами, ссылками для сдачи и комментариями. **Никаких npm-пакетов устанавливать не требуется.**

## Как запустить на компьютере

1. Распакуйте архив полностью в любую папку.
2. Установите **Node.js версии 20 или новее** с https://nodejs.org/ (если ещё не установлен). Для проверки: `node -v` в терминале.
3. В папке проекта запустите `start-windows.bat` (Windows), `start-macos.command` (macOS) или в терминале `node server.js`.
4. Откройте **http://localhost:3000** в браузере.
5. Нажмите «Войти как староста». **Пароль будет напечатан в окне запуска** при первом запуске и записан в файле `data/.admin-password`. Никому не отправляйте этот пароль.
6. При желании удалите демонстрационные задания: «Выйти из режима старосты» → «Убрать примеры» (эта кнопка сначала открывает настройки, затем подтверждение удаления).

Оставляйте окно сервера включённым, пока пользуетесь сайтом. При повторном запуске все записи и вложения остаются на месте.

## Что умеет сайт

| Возможность | Доступ |
| --- | --- |
| Месячная сетка, прокрутка месяцев | Все |
| Обзор 4 недель по 7 дней с датами | Все |
| Полный список домашних заданий, поиск, фильтры | Все |
| Информация о дедлайне и формате сдачи | Все |
| Скачать прикреплённые старостой файлы | Все |
| Открыть ссылку на место сдачи | Все |
| Писать вопросы и комментарии к заданиям | Все |
| Личные отметки «Выполнено» | Все (только в своём браузере) |
| Создание, редактирование, удаление заданий | Староста, с паролем |
| Удаление комментариев, очистка демо-примеров | Староста |

Карточка домашки содержит: **предмет, название, описание задания, дату и время дедлайна, формат сдачи, место сдачи, ссылку, дополнительные пояснения, приоритет, цвет предмета, вложения**. Одна карточка поддерживает до **6 файлов по 8 МБ**.

## Как дать доступ одногруппникам

**На одном компьютере**: `http://localhost:3000` доступен только на этом компьютере. Для постоянного общего сайта разместите проект на хостинге, который запускает **Node.js** и предоставляет **постоянный диск** для папок `data/` и `uploads/`. Команда запуска: `node server.js`; переменная порта `PORT` подставляется хостингом. Подключите HTTPS.

Для изменения названия группы и пароля рекомендуем использовать переменные окружения:

```bash
GROUP_NAME="Моя учебная группа" ADMIN_PASSWORD="мой_сложный_пароль" node server.js
```

Для PowerShell в Windows:

```powershell
$env:GROUP_NAME="Моя учебная группа"
$env:ADMIN_PASSWORD="мой_сложный_пароль"
node server.js
```

**Важно:** простого размещения на GitHub Pages недостаточно: GitHub Pages не запускает сервер и не хранит общий список заданий. Для общего использования нужен работающий Node-сервер. Пока сайт не размещён на хостинге, у одногруппников не будет общей ссылки в интернете.

### Доступ и приватность

- Староста входит с секретным паролем, редактирование заданий защищено на сервере.
- Для **чтения сайта и публикации комментариев** вход не требуется. Не публикуйте приватные сведения и закрытые материалы, если сайт доступен из интернета.
- Имена авторов комментариев вводятся вручную, идентичность студентов не проверяется. Комментарии видны всем посетителям.
- Ссылка «Куда сдавать» ведёт на внешнюю форму/LMS. **Приём готовых работ внутри сайта не предусмотрен** — файлы к заданию прикрепляет староста, а студенты скачивают их.
- Отметка «Выполнено» хранится отдельно в браузере каждого студента и не передаётся другим.
- Для общего сайта используйте HTTPS и надёжный пароль. При необходимости можно добавить аккаунты студентов в следующей версии.

## Резервные копии

Чтобы сохранить **и тексты заданий, и файлы**, скопируйте папки `data/` и `uploads/` вместе. Кнопка «Экспорт JSON» сохраняет только карточки и метаданные вложений, не содержимое файлов.

## Быстрый просмотр без установки Node.js

Отдельный файл `Планер-ДЕМО.html` можно просто открыть двойным щелчком. В нём работает календарь, редактор, комментарии и локальное сохранение. **Это демо для одного браузера**, задания не синхронизируются с одногруппниками. Объём файлов ограничен доступной памятью браузера. Для настоящей общей системы используйте серверную версию.

## Техническая часть

- Node.js 20+, без зависимостей; API и фронтенд на чистом JavaScript.
- Файлы заданий сохраняются в `uploads/`; задания и комментарии — в `data/tasks.json`.
- Защита доступа старосты: cookie HttpOnly / SameSite=Strict с подписью, ограничение попыток входа, валидация входных полей, лимиты файлов; HTML экранируется при показе.
- Адаптивно работает на компьютере и телефоне.
